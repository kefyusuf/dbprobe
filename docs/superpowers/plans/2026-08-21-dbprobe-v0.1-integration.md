# dbprobe v0.1 Integration Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Consolidate the independently verified v0.1 work into one integration candidate without losing architecture boundaries, duplicating portable behavior or claiming capabilities before their live gates pass.

**Architecture:** `integration-v0.1` is the promotion branch. The initial feature branches were consolidated in dependency order. Driver-independent SQLite CLI orchestration was merged through PR #5; the concrete modernc binding, live persistence, driver comparison and final acceptance work are tracked in PR #6.

**Tech stack:** Go 1.25, Cobra, driver-independent `database/sql` persistence, `modernc.org/sqlite` as the accepted production binding, MySQL 8.0/8.4 Docker acceptance and isolated ncruces comparison tooling.

**Spec:** `docs/superpowers/specs/2026-08-21-dbprobe-v0.1-architecture-design.md`

## Global constraints

- Never merge directly to `main` from feature work.
- `internal/core`, `internal/app`, SDK and surfaces remain free of concrete database drivers and adapters.
- Generic `core.*` rules are authoritative and must not be duplicated by adapters.
- MySQL SQL and runtime mechanics remain under `adapters/mysql`.
- Temporal history remains engine-agnostic.
- The generic `internal/platform/sqlite` package depends only on `database/sql` and `database/sql/driver`.
- The concrete SQLite import is allowed only in the leaf binding package `internal/platform/sqlite/modernc`.
- Driver-independent CLI orchestration remains injectable and testable without a concrete driver.
- `inspect` may degrade to a completed stateless report when local history cannot resolve, open, save or close, but `diff` must fail without history.
- Persistence recovery must never rerun target collection.
- Local-history failures exposed through inspect must not leak filesystem, path or driver details.
- Every overlap is resolved intentionally; no source branch is selected wholesale if it would discard integrated behavior.
